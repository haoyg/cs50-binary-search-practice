# Binary Search Practice

A short Python exercise for learners reviewing binary search and inclusive bounds.

Run `python3 practice.py`. Two tests initially fail. Trace the search for
`9` in `[2, 5, 9]`, then ask what happens when both bounds point to the
same element. Fix the loop condition and rerun the tests.

For the lecture context, see the Algorithms section of the
[CS50 Study Pack](https://aivideosummarizer.ai/study-packs/harvard-cs50-2026?utm_source=github&utm_medium=referral&utm_campaign=cs50_binary_search).
